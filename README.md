## Sobre o projeto

Landing page institucional desenvolvida para a **Valora**, empresa especializada em soluções tributárias para negócios de todo o Brasil.

Este projeto foi produzido pela **Cerrado Data** e está sendo utilizado neste repositório como uma apresentação de portfólio, demonstrando o trabalho de criação de interfaces institucionais modernas, responsivas e orientadas à conversão.

## Funcionalidades e destaques

- Página institucional responsiva para desktop, tablet e celular;
- Hero section com proposta de valor e chamadas para ação;
- Apresentação da empresa e dos seus diferenciais;
- Seção com as principais soluções tributárias;
- Destaque visual para a atuação em todo o território nacional;
- Indicadores de credibilidade: mais de 100 empresas atendidas e mais de 3 milhões em dívidas negociadas;
- Botão flutuante e links de contato pelo WhatsApp;
- Formulário rápido para coletar nome, valor aproximado da dívida e assunto;
- Geração automática de mensagem personalizada antes de iniciar a conversa no WhatsApp;
- Links para Instagram e e-mail;
- Estrutura semântica e textos alternativos para melhorar a acessibilidade.

## Soluções apresentadas

- Negociação de dívidas fiscais;
- Gestão de passivos fiscais;
- Defesa em execuções fiscais;
- Revisão de CAPAG;
- Consultoria tributária;
- Transação tributária e parcelamentos.

## Tecnologias utilizadas

- HTML5 semântico;
- CSS3;
- JavaScript puro;
- Elemento nativo `dialog` para o formulário de contato;
- Google Fonts: DM Sans e Playfair Display;
- SVG inline para ícones de contato e redes sociais.
